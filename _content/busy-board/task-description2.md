The task design includes <b>variations in how different inputs produce outputs</b> to examine whether children explore differentially across elements based on their understanding of the different causal connections. We varied the amount of <hi>novelty and predictability</hi> across the elements. For example, there is a circle button with eight colors that foreshadows the output lightbulb’s color; the button thus has high novelty with eight different cycles and high predictability since children can see what the next color will be based on the input. In contrast, there is a crank that children can activate which causes gears to spin for different amounts of time that cycle randomly; this input thus has low novelty and low predictability. There are also three switch inputs that turn on three different lights with different probabilities to see if children interact with the switches differently based on their curiosity about the probabilistic element. Additionally, we incorporated one input element – a lever – that produces no effect on the outputs, which allows us to see if they interact with this element less due to the lack of output. Please see the Appendix for a table with the full list of inputs and outputs.

For <b>longitudinal data collection</b>, we created <b>a second Busy Board layout</b> <hi>(Form B)</hi> so that children will experience a completely new set of cause-effect relations. On repeated assessments, the new form will help maintain children’s interest and minimize any effects of prior task experience on performance. Form B has similar input-output contingencies to Form A, but we changed some superficial design elements (e.g., we replaced colored light bulbs with different colored fruit juices).
