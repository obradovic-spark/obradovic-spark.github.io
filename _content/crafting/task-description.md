The Crafting task is a <b>tablet-based task</b> in which <hi>children combine different objects to discover new objects</hi>. It is designed to <b>measure the number of unique outputs children create as an index for curiosity</b>. This assessment was inspired by several popular children’s computer games that encourage exploration through combining new elements (objects, materials, or concepts) to create something new. For example, Minecraft and Little Alchemist 2.
